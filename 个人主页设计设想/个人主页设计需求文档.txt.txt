智赋青途 · 个人主页「个人画像」功能 —— 需求整理与实现方案
============================================================

【文档说明】
本文档由《个人主页设计需求文档》原始需求整理扩展而来，作为个人画像功能的统一需求与方案底稿。
配套数据文件：`学科目标档位数据.json`（由 7 门学科 docx/doc 档位文档结构化整理生成）。

------------------------------------------------------------
一、需求背景与目标
------------------------------------------------------------
1. 背景：个人主页目前只有「个人资料」（头像/昵称/邮箱/地址/GitHub/简介等身份信息），
   缺少面向学习内容定制的用户信息。
2. 目标：新增「个人画像」功能，采集用户的专业、基础、学习情况与目标，为后续提供
   更精确的内容定制（AI 对话、课程推荐、社群匹配等）打下数据底座。
3. 定位：画像 = “学习定制数据”；资料 = “身份展示数据”。两者分开管理、分开展示。

------------------------------------------------------------
二、核心原则（来自原始需求）
------------------------------------------------------------
1. 新账号注册时必须填写个人画像（不是选填项）。
2. 基本情况可设为必填；其余部分可设为选填（内容过长时可减轻填写负担）。
3. 账号注册完成后，随时可以编辑修改个人画像。
4. 目标岗位选项需覆盖该学科真实就业方向，数据必须核验——
   “不要出现学化学的可以去刷盘子这种答案”。
5. 已学课程选项来自各大院校（软科排名 A+ / A）对应专业培养方案汇总；若查了七八所
   院校后发现没有新课程，即可收手。

------------------------------------------------------------
三、功能范围
------------------------------------------------------------
3.1 注册流程内嵌画像采集（多步注册，方案见第六节）
3.2 个人主页新增「个人画像」展示卡片 + 编辑入口
3.3 学科档位参考数据整理与入库（科目 / 已学课程 / 目标岗位）
3.4 预留后续扩展：AI 内容定制、社群匹配、课程/实训推荐（本阶段不实现）

------------------------------------------------------------
四、字段定义（信息架构）
------------------------------------------------------------
[填] = 可填  [必] = 必填  [选] = 选填  （必填/选填以 待确认 为准，见第九节）

4.1 基本情况
  - 专业           [必] 单选下拉。选项来自学科档位库（化学/物理/生物/数学/经济学/
                       管理学/计算机科学），是否支持「其他/自定义」待确认。
  - 当前年级       [必] 单选。如：大一/大二/大三/大四/硕士研究生/博士研究生（具体
                       档位待确认）。
  - 数学基础       [选] 填空式自评，如“微积分较好，线性代数一般”。
  - 编程基础       [选] 选择或填空，如“Python 入门”。
  - 英语水平       [选] 填空，如“CET-6 600 分”。
  - 目标院校       [选] 文本输入，如“某大学应用经济学”。
  - 目标岗位       [必/选] 多选。按所选专业过滤出岗位候选（来自档位库），支持搜索，
                       是否支持自定义补充待确认。

4.2 学习情况
  - 已学课程       [选] 多选。按所选专业过滤课程候选（来自档位库），支持搜索；
                       课程量较大时考虑按类别分组（基础课/专业核心/工具技能等）。
  - 薄弱内容       [选] 自由添加（标签式），可提供推荐候选，如：消费者理论证明、内生性、
                       时间序列。
  - 每周可投入时间 [选] 单选档位（如 <5h / 5–10h / 10–20h / 20–30h / 30h+），
                       或数字输入（待确认）。

4.3 当前项目（做成选择题）
  - 当前项目       [选] 多选。参考选项：考研专业课复习 / 完成一篇实证论文 /
                       准备暑期实习；是否允许自定义待确认。

4.4 填写时机与校验
  - 新账号注册：随注册流程完成，必填项未填不允许跳过。
  - 注册完成后：个人主页随时可再进入编辑。

------------------------------------------------------------
五、学科档位参考数据（已整理）
------------------------------------------------------------
1. 来源：7 份学科档位文档（docx/doc）：
   化学、物理、生物、数学、经济学、管理学、计算机科学。
2. 现状：已结构化整理为
   `个人主页设计设想/学科目标档位数据.json`，每学科含：
   - 目标岗位列表（38 ~ 114 个/科）
   - 已学课程列表（82 ~ 152 门/科）
3. 用途：
   - 注册/编辑画像表单的目标岗位、已学课程候选项。
   - 后续 AI 内容定制与推荐的知识底座。
4. 数据质量要求：
   - 岗位需核验真实性与相关性（勿出现跨学科无关答案）。
   - 课程来自软科 A+/A 院校培养方案，已去重整理。
5. 落地方式（待确认）：
   - 方案A：前端静态引用 JSON（原型阶段）。
   - 方案B：seed 进 Supabase 参考表 `subject_tiers`，前端查询（推荐，正式接入时用）。

------------------------------------------------------------
六、交互与页面设计（草案）
------------------------------------------------------------
6.1 注册流程
    Step1 账号信息：邮箱 / 昵称 / 密码
    创建账号成功后，引导用户填写内容：
    Step2 个人画像：专业→年级→目标岗位→已学课程→（其余选填）
    将画像写入用户画像表；未填必填项不允许提交。

6.2 个人主页展示
  - 现有「个人资料」卡片保持不变（头像/昵称/地址/GitHub/简介）。
  - 新增「个人画像」区块：专业、年级、基础水平、目标院校、目标岗位、已学课程、
    薄弱内容、每周投入时间、当前项目。
  - 页面布局：置于资料卡下方或右侧，或作为独立标签页（如「画像」tab）。
6.3 编辑入口
  - 「个人画像」区块右上角「编辑」按钮 → 弹出表单或跳转编辑页。
  - 保存后即时刷新本地展示与 store。

------------------------------------------------------------
七、数据模型与存储方案（已按此落地）
------------------------------------------------------------
独立用户画像表（已实现）
  user_portraits
    user_id          uuid PK → profiles.id（on delete cascade）
    major            text not null        -- 专业（必填）
    grade            text not null        -- 当前年级（必填）
    math_basis       text default ''      -- 数学基础
    programming_basis text default ''     -- 编程基础
    english_level    text default ''      -- 英语水平
    target_university text default ''     -- 目标院校
    target_careers   jsonb default '[]'   -- 目标岗位（数组，多选）
    learned_courses  jsonb default '[]'   -- 已学课程（数组，多选）
    weak_points      jsonb default '[]'   -- 薄弱内容（数组，自由添加）
    weekly_hours     text default ''      -- 每周可投入时间
    created_at / updated_at timestamptz
  RLS：仅本人 select / insert / update（与 profiles 一致）。
  （注：Q6 已确认不做 current_projects）
  配套参考表（已实现 + seed）
  subject_tiers
    id       bigint identity PK
    subject  text unique   -- 学科名
    careers  jsonb         -- 目标岗位候选
    courses  jsonb         -- 已学课程候选
    sort_order int         -- 排序
    （由 学科目标档位数据.json 生成 seed：20260328000005）

八、后续扩展（本阶段不实现，仅记录方向）
------------------------------------------------------------
1. AI 内容定制：Agent 对话时读取画像 → 按专业/基础/目标定制回复与学习路径。
2. 社群功能：按专业/目标岗位/当前项目匹配同频用户，形成学习小组。
3. 推荐系统：基于目标岗位与已学课程推荐课程、实训、岗位资讯。
4. 画像自画像动态化：随学习记录自动更新“已学课程/薄弱内容”。

十、落地状态（2026-08 已实现一版）
------------------------------------------------------------
1. 已落地：
   - DB：`user_portraits` 独立表（1:1 profiles，RLS 本人读写）、`subject_tiers` 参考表；
     seed 已由 学科目标档位数据.json 生成（20260328000004 / 20260328000005）。
   - 个人主页：新增「个人画像」卡片（概览展示 + 编辑/完善入口）；
     未完善画像时登录后自动弹出引导弹窗（方案B）。
   - 编辑表单：专业（下拉+自定义）、年级（下拉+自定义）、数学/编程/英语/目标院校（自由填写）、
     目标岗位（多选+搜索+自定义）、已学课程（多选+搜索+展开分页+自定义）、
     薄弱内容（自由添加）、每周可投入时间（档位+自定义）。
   - 前端服务：`src/services/portraitService.ts`（读/存画像、读档位数据）、
     `src/types/portrait.ts`、组件 `src/components/PortraitEditor.tsx`。
2. 说明：
   - 目标岗位未强制必填（按 Q2 基本情况必填为主，专业/年级必填，其余选填）。
   - 前端从 `subject_tiers` 参考表读档位候选；未选专业时不展示候选但可自定义输入。
3. 后续扩展方向（第八节）：AI 内容定制、社群匹配、推荐系统、画像动态化。
